## 📖 About The Project

ShopZone is a complete e-commerce frontend built in 6 structured parts. It covers everything from a responsive home page to a fully working shopping cart — making it a great project for learning how real e-commerce sites are built from scratch.

---

## ✨ Features

- ✅ Fully responsive — works on mobile, tablet & desktop
- ✅ Multi-page structure with consistent nav & footer
- ✅ Interactive shopping cart with live totals
- ✅ Single product detail page
- ✅ Blog, About & Contact pages
- ✅ Pure vanilla JavaScript — zero dependencies

---

## 🗂️ Project Sections

### Part 1 — Responsive Home Page Design

- Hero banner with call-to-action
- Featured products grid
- Newsletter subscription section
- Responsive navbar with mobile menu
- Branded footer with links and social icons

### Part 2 — Shop Page & Single Product Page

- Product listing grid with filter layout
- Product cards with image, name, price and rating
- Single product detail page with image gallery
- Add to cart button connected to cart logic

### Part 3 — Blog Page

- Blog post cards with thumbnail, title and excerpt
- Category/tag labels on each article card
- Clean responsive grid layout

### Part 4 — About Page

- Brand story and mission statement
- Team member cards with photo and role
- Stats/milestones section

### Part 5 — Contact Us

- Contact form with name, email and message fields
- Store address, phone and email info
- Clean, accessible and responsive form design

### Part 6 — Ecommerce Shopping Cart

- Slide-in cart sidebar triggered by cart icon
- Add to cart from any product page
- Increase / decrease item quantity
- Remove individual items
- Live subtotal and total price calculation
- Cart item count badge on navbar icon

## 🚀 Getting Started

### Prerequisites

No installations needed! This is a pure HTML/CSS/JS project.

### Run Locally

1. Clone the repository:

```bash
git clone https://github.com/babalonogqala23/Build-and-Deploy-Ecommerce-Website-main.git
```

2. Open the project folder in **VS Code**

3. Open `index.html` in your browser — or install the **Live Server** extension in VS Code for hot reload
